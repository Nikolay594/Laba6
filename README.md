### 1. Алгоритм

1. Начать программу.  
2. Объявить переменные `x` и `y` типа `double`.  
3. Ввести с клавиатуры значения `x` и `y`.  
4. Проверить условие:  
   x >= 2.0 && x*x + y*y <= 36.0
5. Если условие истинно → вывести `YES`.  
6. Иначе → вывести `NO`.  
7. Завершить программу.
